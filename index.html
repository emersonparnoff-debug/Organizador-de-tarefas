Como funciona a sincronização entre usuários:

Certifique-se de que todos os usuários digitem o mesmo nome no campo Sala no topo da página (por padrão: GERAL). Qualquer tarefa criada, movida ou concluída aparece automaticamente para todos em tempo real.

Se aparecer erro de "Banco Não Criado" ou "Permissão Negada" no Firebase:

  1. Abra diretamente o painel do seu projeto clicando aqui: Abrir Firestore no Firebase Console
  2. Se ainda não houver banco criado, clique em Criar banco de dados (Create database) e escolha Iniciar no modo de teste (Test mode).
  3. Na aba Regras (Rules) do Firestore, cole as regras abaixo e clique em Publicar (Publish):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
