Como ativar o banco de dados na nuvem (caso apareça "Modo Local / Sem Permissão"):

  1. Acesse o Firebase Console no projeto organizador-de-tarefas-fadc1.
  2. No menu lateral esquerdo, clique em Criação (Build) → Firestore Database e clique em Criar banco de dados.
  3. Selecione Iniciar no modo de teste (Test mode) ou acesse a aba Regras (Rules) e cole a regra abaixo:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tarefas/{document=**} {
      allow read, write: if true;
    }
  }
}

Enquanto o Firestore não estiver ativo no painel do Firebase, todas as suas tarefas continuam salvas automaticamente no localStorage do navegador.
